# Aide scolaire

Version en ligne de l’application d’aide scolaire pour le CE2 et la 6e (programmes 2026-2027) :
cours, fiches, exercices et devoirs. L’adresse garde son nom d’origine (aide-scolaire-6e) pour
ne pas casser les installations existantes.

Ce dépôt ne contient que l’application construite. Les données de l’élève (profils,
progression) restent sur son appareil.
